# 🏍️ Highway Moto Rush

A browser-based motorcycle racing game built using **HTML, CSS, and JavaScript**.

Ride through a busy highway, dodge traffic, use Nitro Boost, and try to achieve the highest score. Be careful while overtaking vehicles because one collision can end your ride!

## 🎮 Play the Game

**Live Demo:** [Play Highway Moto Rush] https://highway-moto-rush.vercel.app

## ✨ Features

- **Motorcycle Movement:** Steer left and right to avoid traffic.
- **Nitro Boost:** Activate Nitro for a temporary speed boost.
- **Dynamic Traffic:** Encounter cars moving at different speeds.
- **Lane Changing:** Some traffic vehicles can change lanes.
- **Near-Miss Bonus:** Earn extra points by narrowly avoiding vehicles.
- **Score System:** Track your current score and best score.
- **Best Score Storage:** Your best score is saved using browser local storage.
- **Increasing Difficulty:** Traffic speed and difficulty increase as the game progresses.
- **Collision Detection:** Crashing into another vehicle ends the game.
- **Crash Effects:** Includes crash particles and sound effects.
- **Start and Pause Screens:** Start the game and pause or resume whenever needed.

## 🕹️ Controls

| Key | Action |
|---|---|
| `←` or `A` | Move Left |
| `→` or `D` | Move Right |
| `SPACE` | Activate Nitro Boost |
| `P` | Pause / Resume |

## 🚀 Run Locally

You can run the game on your computer without installing any additional packages.

1. Clone the repository:

   ```bash
   git clone https://github.com/hemanth24408/game.git
   ```

2. Open the project folder:

   ```bash
   cd game
   ```

3. Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code to run the game.
